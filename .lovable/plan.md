# Plano: Arquivar e compartilhar o Vitalis·Sim v0.2

## Objetivo
Entregar uma cópia compactada do projeto atual e orientar sobre as formas de compartilhamento/arquivamento disponíveis.

## O que será feito

1. **Gerar um arquivo zip do projeto**
   - Compactar todo o conteúdo do repositório, excluindo `node_modules`, `.git`, logs e arquivos temporários.
   - Salvar o zip em `/mnt/documents/vitalis-sim-v0.2.zip`.
   - Apresentar o arquivo como artefato no chat para download imediato.

2. **Documentar as opções de compartilhamento**
   - **Download do zip**: arquivo gerado nesta conversa, ideal para backup local ou envio por e-mail.
   - **GitHub**: conectar o projeto a um repositório para versionamento contínuo e colaboração.
   - **Publicar no Lovable**: gerar uma URL pública da aplicação em execução.
   - **Lovable editor**: acessar o projeto diretamente em lovable.dev para edição e compartilhamento por link.

## Fora do escopo deste plano
- Configurar GitHub, publicação ou domínio customizado.
- Alterar código ou adicionar funcionalidades.

## Resultado esperado
Um arquivo `vitalis-sim-v0.2.zip` disponível para download e um resumo das alternativas de compartilhamento.
